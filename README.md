### What I Work On

* **Kubernetes-native virtualization**

  Building [KubeSwift](https://github.com/kubeswift-io/kubeswift), a Cloud Hypervisor-first platform for running lightweight virtual machines and isolated OCI workloads as native Kubernetes resources. Its focus includes GPU passthrough, Kubernetes DRA, VM fleets, snapshots, sandboxes, and migration.

* **Cloud Hypervisor orchestration**

  Building [vQuasar](https://github.com/vquasar/vquasar), an open-source virtualization management platform built directly around Cloud Hypervisor. It manages fleets of Linux hypervisor hosts through a central control plane, per-host agents, reconciled VM resources, Open vSwitch networking, and live migration.

* **Multi-hypervisor infrastructure**

  Building [VirtRigaud](https://github.com/projectbeskar/virtrigaud), a Kubernetes operator for managing virtual machines across VMware vSphere, Libvirt/KVM, and Proxmox VE through a unified API, including migration between different hypervisors.

* **Immutable edge and bare metal**

  Maintaining [Kairos](https://github.com/kairos-io/kairos), contributing to its Cluster API integration, and developing [Beskar7](https://github.com/projectbeskar/beskar7) for Kubernetes-native bare-metal lifecycle management.

* **AI and GPU platforms**

  Exploring GPU scheduling, confidential workloads, agent sandboxes, distributed inference, hardware isolation, and platform patterns for operating AI in regulated environments.

* **Enterprise platform engineering**

  Helping organizations design, build, and operate Kubernetes platforms spanning cloud, bare metal, sovereign infrastructure, edge locations, and financial-services environments.
